📉 알바생 계좌 잔고 수호기 (Flexible Balance Protector)

> **"돌아가는 못난 앱이 안 돌아가는 멋진 계획보다 백번 낫다."**
> 매주 들쭉날쭉한 유동 지출 때문에 맨날 텅장이 되는 대학생들을 위한 초간단 미래 잔고 예측 웹앱입니다.

## 1. 문제 정의 (Project Background)
현재 많은 대학생들이 학업과 알바를 병행하며 생활비를 직접 관리하고 있습니다. 하지만 기존의 자산 관리 앱들은 매일 영수증을 수동으로 입력해야 해서 귀찮고, 가장 중요한 '매주 지출이 불규칙하고 유동적이다'라는 현실을 반영하지 못합니다. 
어떤 주는 시험 기간이라 돈을 안 쓰지만, 어떤 주는 종강 총회나 약속 때문에 과소비를 하게 됩니다. 고정된 평균값만 계산하는 기존 방식은 현실성이 떨어져 결국 재정 관리를 포기하게 만들고, 사소한 충동구매를 유발하여 월말마다 계좌가 거덜 나는 문제를 일으킵니다.

## 2. 주요 기능 (Core Features)
- **알바 수입 자동 연산:** 사용자가 시급과 주당 근무 시간만 입력하면, 한 달 평균 주차(4.345주)를 계산하여 예상 월급을 자동으로 계산합니다.
- **유동 지출 시나리오 분리:** 매주 지출이 바뀌는 유동성을 잡기 위해 사용자의 주간 지출을 [평소 아껴 쓰는 주 지출]과 [약속/쇼핑 등으로 과소비하는 주 지출] 두 가지로 나누어 입력받습니다.
- **최선 vs 최악 미래 예측:** 현재 재정 흐름을 바탕으로 목표 잔고까지 도달하는 데 각각 몇 개월이 걸리는지 두 가지 시나리오(🟢최선 / 🔴최악)로 비교하여 보여주고, 적자일 경우 경고 문구를 출력합니다.
- **예외 처리 및 방어 코드:** 빈칸이 있거나 숫자가 아닌 문자(예: 한글)를 입력해도 프로그램이 강제 종료(크래시)되지 않고, "숫자만 정확히 입력해 주세요"라는 안내 메시지를 띄워 안전성을 확보했습니다.

## 3. 실행 방법 (How to Run)
1. 구글 코랩(Google Colab) 환경에서 제공된 파이썬(Python 3) 소스코드를 복사하여 코드 블록에 붙여넣습니다.
2. `Ctrl + Enter`를 눌러 코드를 실행합니다.
3. 잠시 후 콘솔 창 하단에 생성되는 `Running on public URL: https://xxxx.gradio.live` 형태의 공유 웹 링크를 클릭합니다.
4. 웹 UI 화면에서 데이터를 입력하고 '미래 잔고 시나리오 연산하기' 버튼을 누릅니다.
