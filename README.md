## 01 프로젝트 이름
알바생 계좌 잔고 수호기 (유동 지출을 반영한 최선/최악 미래 예측 계산기)

## 02 문제 · 사용자 1문장
매주 지출이 유동적이라 계획 없이 돈을 쓰다 보니 계좌 잔고가 매달 거덜 나는 대학생(사용자)이, 평소 지출과 과소비 지출을 분리해 계산해 주는 미래 잔고 시나리오 도구(해결책)를 통해, 내 나쁜 소비 습관이 목표 달성을 얼마나 지연시키는지 직관적으로 자각하고 주간 지출을 스스로 통제하게 만듭니다.

## 03 핵심 기능 3개
- **알바 수입 월급 자동 환산:** 시급과 주간 근무 시간만 입력하면 한 달 평균 주차(4.345주)를 자동으로 연산해 예상 월 수입을 도출합니다.
- **유동 지출 시나리오 다각화:** 매주 쓰는 돈이 달라 예측이 어려운 점을 해결하기 위해 `[평소 아껴 쓰는 주 지출]`과 `[약속/쇼핑 등으로 과소비하는 주 지출]`의 두 가지 범주를 분리하여 대입할 수 있게 합니다.
- **최선 vs 최악 미래 예측 및 예외 처리:** 현재 소비 패턴을 기반으로 목표 잔고까지 도달하는 데 걸리는 시간(X.X개월)을 최선/최악 버전으로 비교해 주며, 실수로 빈칸을 두거나 문자를 적어도 앱이 꺼지지 않게 에러를 안전하게 방어합니다.

## 04 실행 방법 · 앱 링크
1. 구글 코랩(Google Colab) 환경에서 작성한 파이썬 소스코드를 복사하여 실행(`Ctrl + Enter`)합니다.
2. 코드 블록 하단에 실시간으로 생성되는 public 외부 공유 URL 링크를 클릭하여 웹브라우저에서 실행합니다.
- **앱 구동 링크:** `Running on public URL: https://xxxx.gradio.live` (코랩 실행 후 뜨는 유동 링크로 접속)
